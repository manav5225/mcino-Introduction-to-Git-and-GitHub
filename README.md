# Simple Interest Calculator

This project is a **Simple Interest Calculator** built as a Bash script. It allows users to calculate simple interest based on three inputs: the principal amount, the rate of interest, and the time period.

## Features
- Takes principal amount as input
- Takes rate of interest as input
- Takes time period as input
- Calculates and displays the simple interest using the formula:

  Simple Interest = (Principal × Rate × Time) / 100

## Usage
Run the script `simple-interest.sh` in a terminal and follow the prompts to enter the principal, rate, and time period. The script will output the calculated simple interest.
